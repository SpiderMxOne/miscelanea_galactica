# Sitio Web de Miscelánea Galáctica (GitHub Pages)

Este directorio (`/app/web/`) contiene el sitio web oficial de la aplicación, incluyendo la landing page de presentación y las páginas legales obligatorias para Google Play y AdMob.

## Archivos Incluidos:
- `index.html`: Página principal / Landing Page con temática retro-arcade synthwave.
- `privacy.html`: Política de Privacidad (requisito para Google Play Console y AdMob).
- `terms.html`: Términos y Condiciones.

---

## 🚀 Cómo Alojarlo en GitHub Pages:

1. Sube tu repositorio a GitHub.
2. Ve a la configuración de tu repositorio en GitHub (**Settings**).
3. En el menú lateral izquierdo, haz clic en **Pages**.
4. En **Build and deployment -> Source**, selecciona **Deploy from a branch**.
5. En **Branch**, selecciona la rama principal (`main` o `master`) y cambia la carpeta de `/ (root)` a `/app/web` (o sube los archivos de esta carpeta a la rama `gh-pages`).
6. Guarda los cambios. En unos minutos, GitHub te proporcionará la URL pública de tu sitio web (ej. `https://tuusuario.github.io/MiselaneaGalactica/`), la cual podrás usar directamente en tu ficha de Google Play Console en el apartado de **Política de Privacidad**.
